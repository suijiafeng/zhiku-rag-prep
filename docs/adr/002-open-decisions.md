# ADR-002：阻塞真实 RAG 的决策
状态：待确认，不得由 AI 静默填空。
1. 试点主题（人事制度只是 PRD 建议）、授权企业/受众、业务负责人、业务时区、样本准入。
2. 身份源/角色/会话方案；Widget 是否仅受控演示，允许宿主和短期令牌方案。
3. 模型供应商、可外传数据等级、预算/限额/网络、embedding 模型版本、维度与距离度量；不默认接外部网关。
4. 版本冲突/替代和适用对象规则；确认当前/历史/未来查询语义。
5. 质量目标、人工兜底渠道、日志/历史/审计保留期。
确认后记录负责人、日期、依据和影响，再添加 provider、schema 或生产接口。未知输入只允许 fixture 和接口讨论。
